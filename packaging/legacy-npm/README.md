# @byerlikaya/claude-starter-kit

Renamed to **crewforth**. Use `npx crewforth`. This package only forwards.

Every command you ran with this package works the same under the new name:

```bash
npx crewforth init     # a new project
npx crewforth adopt    # an existing project
npx crewforth update   # refresh an installed one
```

More: [crewforth.com](https://crewforth.com).
